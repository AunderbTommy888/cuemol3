CueMol 3.0.1 (build 555)

The main changes:

- **Fetching from more databases (CueMol3)**: Get PDB and the consoles can
  fetch from PDBe, PDBj, PDB-REDO, AlphaFold DB and PubChem, EMDB maps from
  PDBj, and density maps from URLs.
- **Multi-colour B-factor gradients (CueMol2 core and CueMol3)**: B-factor
  colouring can use a gradient of any number of colours; AlphaFold models are
  coloured by pLDDT when fetched.
- **ChX console (CueMol3)**: many more ChimeraX commands and forms, checked
  against the official ChimeraX tutorials and figure scripts. Unsupported
  parts of a script are skipped with a warning instead of stopping it.
- **Startup scripts and style files (CueMol3)**: `~/.cuemol/` can hold
  scripts run at launch and extra style files.

---

## Fetching entries and maps (CueMol3)

- **Get PDB** has a **Database** switch (PDB / EMDB, AlphaFold DB, PubChem)
  and, for a PDB entry, a **Server** (RCSB, PDBe, PDBj, PDB-REDO). AlphaFold
  and PubChem entries are looked up before download (protein name, gene,
  organism, mean pLDDT / compound name, formula, weight).
- AlphaFold models are coloured by pLDDT (ChimeraX's `alphafold` colours)
  as they are fetched. A PubChem compound opens as ball-and-stick.
- **EMDB maps from PDBj**, besides wwPDB and EBI (Get PDB's Cryo-EM maps
  Source, `fetch_emdb ... PDBJ`).
- New console ops `fetch_entry` (any of the sources above; recorded so a
  replay fetches the same entry) and `fetch_map_url` (a CCP4 / MRC map from a
  URL, `.gz` included, drawn as cryo-EM or crystallographic by what it
  contains).
- A real PDB-REDO download could not be verified (pdb-redo.eu was down during
  testing).

## Multi-colour B-factor gradients (CueMol2 core and CueMol3)

- B-factor colouring takes a gradient of two or more colours over the
  absolute value (B-factor, occupancy or distance). Edits to the gradient
  can be undone and are saved in the scene.
- **Color pane** (CueMol3): the B-factor deck has a multi-colour gradient
  switch, the gradient editor with a histogram of the atom values, and an
  AlphaFold pLDDT preset.
- **PyM console**: `spectrum b` / `q` with three colours or more
  (`rainbow`, `blue_white_red`, ...) is drawn as a multi-colour gradient, as
  PyMOL draws it.

## View fitting (CueMol2 core and CueMol3)

- EMDB maps were framed on the unit cell and came out off-centre; maps are
  now fitted to their data, and an EM map is fitted to its shown isosurface
  when opened.
- **Focus** fits a molecule to its shown atoms and a map to its shown
  contour. Fitting never zooms closer than 15 A, so a single atom does not
  fill the screen.
- A molecule and a map with the same name are no longer mixed up (map
  boundaries, colouring by map, surfaces, `around` selections).

## ChX console (CueMol3)

The console names are now **PyM console** and **ChX console**, as in the
CueMol3 documentation (Settings > Plugins shows these names).

- **Scripts run to the end**: a command, keyword or specification the
  console does not support is skipped with a warning, and the rest of the
  script runs. Other errors still stop it.
- **open**: database prefixes as ChimeraX (`pdbe:`, `pdbj:`, `redo:`,
  `alphafold:`, `pubchem:`, `emdb:`, ..., `fromDatabase`), URLs, several
  names at once, `from eds` (2Fo-Fc map as a grey mesh), `from rcsb_bio` /
  `pdbe_bio`, `alphafold fetch`. The first `open` into an empty scene sets
  the view; later ones leave it alone, as in ChimeraX.
- **New commands**: `volume` (`level`, `style`, `color`, `transparency`,
  `step`, `zone`, `sdLevel` / `rmsLevel`, ...), `lighting` (approximated
  with ambient occlusion, with warnings), `preset`, `camera`, `nucleotides`,
  `ribbon`, `unitcell`, `dssp`, `wait`, `color modify`, `color bynucleotide`,
  `color fromatoms` / `fromcartoons`, `color bfactor` / `byattribute`,
  ColorBrewer palettes.
- **Nucleic acids**: bases drawn as slabs or a ladder; `cartoon style
  modeHelix tube` draws cylinder helices.
- **Display**: hidden atoms shown again come back in the style they had
  (sticks stay sticks), and undo / redo restore it. `show ... only`, comma
  lists (`hide atoms,ribbon`), `show` on a map.
- **Specifications**: element symbols are no longer read as command
  abbreviations (`select C & :sti`), `view <spec>` works, model parts one
  after another are a union (`#1/k#2/o`), names may name models, `@@display`,
  `ions`.
- **Other**: model numbers are reused after `close` as in ChimeraX, Tab after
  `#` completes model numbers, repeated colouring no longer slows a large
  molecule, silhouettes outline every edge and keep their pixel width while
  zooming, `label height` / `font`, `save .stl`.
- `color random` and `color zone` are refused; see
  `docs/architecture/console-chimerax-dialect.md` for what else differs from
  ChimeraX.

## Native console (CueMol3)

- Commands run only by their full names. `open 1a0m 1crn` typed in the
  native console used to run `open_log` and write a log file; it now says
  `unknown command: "open" (did you mean open_log?)`. Tab still completes
  abbreviations, and the PyM console keeps PyMOL's abbreviations.

## Startup scripts and style files (CueMol3)

- `~/.cuemol/` (or `$CUEMOL_HOME`) can hold `startup.txt` / `.qax` / `.pml`
  / `.cxc`, run in the console once per launch (each one undo step), and
  `styles/*.xml`, loaded as read-only style sets.
- Files opened from the OS or `tritium_cli` wait until the scripts finish. A
  status bar item shows the running scripts and can stop them.
